Méthode v2.1 : plus de fichier de base — la mémoire, le mode auto, les loops et le navigateur

Claude · HL · 2 septembre 2026 · Perso
metaagentdocen-prodPerso

Contexte

Hier, la Méthode v2 décrivait deux couches de contexte : des fichiers CLAUDE.md versionnés (« comment travailler avec moi ») et le Brain (« ce qu'on sait »). C'était déjà faux le jour de la publication, et c'est moi qui l'ai signalé en relisant : depuis l'été, je n'ai plus de fichier de consignes de base. Ma façon de piloter l'IA a changé sur quatre points en un mois — la mémoire, le mode auto, les loops et routines, le navigateur — et le site devait le dire.

Ce qui a été fait

  • Plus de fichier de base. Depuis le 25 août, la mémoire de Claude est unique entre le chat et Cowork, activée par défaut, relisible et corrigeable sujet par sujet ; Claude Code tient une mémoire automatique par projet, où il note lui-même mes corrections. Le ton, les principes, « une question à la fois », mon métier : retenus, pas recopiés. Ce qui reste écrit à la main : le CLAUDE.md d'un dépôt de code — conventions, commandes, interdits — court, versionné, lu par tout humain ou agent qui y travaille. Ce site en a un ; c'est un règlement intérieur, plus un fichier de personnalité.
  • Le mode auto. Par défaut dans Claude Code depuis le 14 août : on ne valide plus chaque commande, un classifieur relit chaque action, mes interdits écrits passent avant lui. Ma pratique : je valide le résultat — le diff, le script de santé, la page en ligne — et les écritures dans mes outils métier restent derrière un aperçu et un bouton.
  • Les loops et les routines. Une part croissante du travail ne se passe plus dans une conversation, elle tourne : une loop pour surveiller un déploiement cet après-midi, une routine hebdomadaire de cohérence en lecture seule, les tâches planifiées maison pour ce qui doit tourner pour toujours.
  • Le navigateur. Depuis le 26 août, Claude navigue : l'extension Claude dans Chrome sur mon propre navigateur, ou le navigateur intégré de Cowork, séparé de mes onglets et mots de passe. C'est la porte pour tout ce qui n'a pas de connecteur — portails fournisseurs, back-offices, démarches — avec la même règle : Claude lit et remplit, le clic qui engage reste le mien.
  • Sur le site : la Méthode réécrite en v2.1 (douze sections, nouveau prompt de départ sans fichier), et treize guides ajustés — le CLAUDE.md « quand il en faut encore un », le contexte, Chat/Cowork/Code avec une section navigateur, les loops, les agents (cinq formes), les skills, le Brain, le prompt, les principes, le Compound Engineering, les garde-fous avec le mode auto, les données, le commerçant. Le lexique suit (mémoire, mode auto, navigation, CLAUDE.md redéfinis).

Ce qui était difficile / inattendu

Admettre qu'une page écrite la veille était déjà datée. La Méthode v2 avait été réécrite « à la date du jour » le 1er septembre, à partir du Brain — et le Brain lui-même décrivait encore les profils CLAUDE.md d'août. Un brain périmé est pire qu'un brain vide : la fiche Profils Claude est à mettre à jour, et c'est un acte que je ferai moi, pas une synchro.

Ne pas jeter le fichier avec la personnalité. La tentation était d'écrire « le CLAUDE.md est mort ». C'est faux : le fichier d'un dépôt n'a jamais été aussi utile, précisément parce que le mode auto exécute sans demander. Ce qui disparaît, c'est le fichier de base ; ce qui reste, c'est le règlement intérieur.

Stack

Claude Fable 5.1 dans Claude Code (session cloud), la veille IA du site comme chronologie (mémoire unifiée le 25 août, navigateur Cowork le 26, mode auto le 14), vérification sur le web des dates et des périmètres (Claude dans Chrome en disponibilité générale sur tous les forfaits payants ; le classifieur du mode auto et l'étude d'Anthropic sur un millier de testeurs), les générateurs de pages de la session, le contrôle de cohérence du site.

Ce que ça illustre

Une méthode avec l'IA se périme en semaines, pas en mois. Le réflexe qui sauve n'est pas de tout réécrire à chaque annonce, c'est d'avoir un endroit daté où l'on dit ce qui a changé — et de laisser à la mémoire ce qui n'a plus besoin d'être écrit.
