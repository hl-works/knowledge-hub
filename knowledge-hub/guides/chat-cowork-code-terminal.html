Chat, Cowork ou Code : lequel utiliser (et le fameux « terminal »)

Trois façons d'utiliser Claude selon la tâche — discuter, déléguer, agir — et la vérité sur le « terminal », qui fait peur mais s'installe en une commande. Avec ce qui a changé en 2026 : Cowork partout, Code dans le navigateur et sur mobile, et des routines qui tournent sans ta machine.

En 30 secondes

  • Chat : tu discutes, il produit du texte, des analyses, des idées — avec sa mémoire et tes outils connectés. L'interface que tu connais déjà.
  • Cowork : tu lui délègues un vrai travail de bureau (préparer un doc, dépouiller des fichiers, remplir un formulaire dans son navigateur intégré, exécuter une routine) — pensé pour les non-développeurs, sur ordinateur, web et mobile.
  • Code : il agit directement sur tes fichiers, ton projet, ton site — l'option la plus puissante. Dans le « terminal » (une commande à coller), mais aussi dans le navigateur, l'application ou le téléphone, où la session tourne dans le cloud.

1. Chat, Cowork, Code : lequel pour quoi

Ce sont trois portes d'entrée vers le même Claude, à choisir selon ce que tu veux faire :

  • Chat (web, mobile, appli) — la conversation. Pour réfléchir, rédiger, analyser un document, préparer une stratégie. 90 % des gens commencent et restent ici, et c'est très bien. Chez moi, c'est là que s'écrit tout ce qui a ma voix — et on s'arrête au texte validé : pas de HTML, pas de mise en ligne.
  • Cowork — un assistant qui exécute un travail de bureau de bout en bout, pour quelqu'un qui ne code pas. Il manipule des fichiers, un tableur, une présentation ; il ouvre un navigateur dans son panneau pour remplir un formulaire ou terminer une démarche ; il exécute des routines planifiées ; il partage sa mémoire avec le chat. La marche entre « discuter » et « déléguer ».
  • Code — l'agent qui met les mains dans le cambouis : il lit et modifie tes fichiers, lance des commandes, gère un dépôt de code, déploie un site, met à jour tout le maillage d'une page. C'est avec ça que je fais tourner Cobra et que je publie ce site. Pas réservé aux devs : c'est juste le niveau « il agit, il ne se contente pas de répondre ».

Ma règle de frontière, qui structure tout mon travail : Chat rédige, Code exécute. Une session Chat produit un texte validé ; Code le transforme en livrable. Les deux moitiés n'ont pas le même critère de succès — la justesse du propos d'un côté, la conformité au gabarit de l'autre — et les mélanger dans une même session, c'est perdre les deux. Détail dans ma méthode.

2. C'est quoi « le terminal », et pourquoi ça ne doit pas te bloquer

Le terminal, c'est juste une fenêtre où on tape des commandes au lieu de cliquer sur des boutons. Ça a un côté « film de hacker » qui intimide, mais c'est une interface comme une autre.

Et surtout : tu n'as pas besoin de le maîtriser. La stratégie est bête comme chou — tu copies, tu colles, tu valides. Si une commande coince, tu colles l'erreur à Claude et il te dit quoi faire. Tu apprends en marchant, sans cours préalable.

3. Installer Claude Code, vraiment facilement

Plus besoin de rien installer d'autre : une seule commande à coller dans le terminal.

Sur Mac (ou Linux) — ouvre le Terminal, colle, Entrée :

curl -fsSL https://claude.ai/install.sh | bash

Sur Windows — ouvre PowerShell, colle, Entrée :

irm https://claude.ai/install.ps1 | iex

Puis tu vérifies, et tu lances :

claude --version
claude

Au premier lancement, il ouvre ton navigateur pour te connecter à ton compte Claude. Il faut un abonnement payant — et bonne nouvelle : tous les forfaits payants incluent Claude Code et Cowork, du forfait Pro (une vingtaine de dollars par mois) aux forfaits Max ; ce qui change entre eux, c'est le volume d'usage.

Et si vraiment le terminal te rebute, tu as trois autres portes : l'application de bureau (Mac/Windows) qui fait tourner Claude Code sans terminal, Claude Code dans le navigateur (la session tourne dans le cloud, sur une copie de ton projet, sans rien installer), et l'application mobile — je lance des corrections depuis mon téléphone, et je vérifie en ligne une minute après.

Détails officiels : code.claude.com/docs/en/setup.

4. Faut-il un gros ordi ? (Non.)

Démystifions : tout le calcul se passe sur les serveurs d'Anthropic, pas sur ta machine. Tu n'as pas besoin d'une carte graphique de gamer ni d'un monstre — ton ordi ne fait qu'envoyer et recevoir du texte.

Il y a un an, je conseillais une machine qui reste allumée 24/7 pour héberger ses automatisations. C'est de moins en moins nécessaire : Claude Code sur le web et Cowork exécutent dans le cloud, et les routines planifiées tournent sans ta machine. Mon petit Mac allumé en permanence ne sert plus qu'à ce qui doit vraiment tourner chez moi. Le vrai confort d'un bon ordi, c'est de faire tourner plusieurs sessions en parallèle sans ramer — pas la puissance de calcul.

5. Ce qui a changé en 2026

Pour ceux qui avaient lu la première version de ce guide, en mai :

  • Cowork est sorti du bureau. Ordinateur, web et mobile pour tous les forfaits payants (août) ; un navigateur intégré pour finir une démarche en ligne ; la possibilité d'apprendre une compétence à Claude en filmant son écran ; une mémoire partagée avec le chat ; des routines planifiées ; une place de marché de plugins.
  • Code a quitté le terminal. Navigateur, application de bureau, mobile — la session tourne dans le cloud. Le mode Auto (Claude décide seul des permissions courantes, avec des protections contre les manipulations) est devenu le défaut en août. Les sous-agents travaillent en arrière-plan, les workflows orchestrent plusieurs agents, les Artifacts produisent des pages partageables depuis une session, et une commande de nettoyage range skills et fichiers de contexte inutilisés.
  • Chat agit. Les connecteurs ne lisent plus seulement : Claude peut envoyer une réponse dans Gmail ou ranger un fichier dans Drive, avec validation sur les actions qui comptent.
  • Les modèles. La famille Claude 5 — Sonnet 5, Opus 5, Fable 5.1 — a rendu Code capable de tâches autonomes de plusieurs heures. Ce n'est plus « il écrit une fonction », c'est « il livre une fonctionnalité, testée ».
