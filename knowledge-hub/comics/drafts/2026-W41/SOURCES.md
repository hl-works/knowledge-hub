# Pilote 2026-W41 — sources et choix éditoriaux

Période : 5–11 octobre 2026. Préparation rétrospective : 16 octobre. Statut : brouillon ; aucun accord de publication enregistré.

Les quatre sujets viennent du flux public existant `veille-ia/feed.json`. Les pages d’annonce des éditeurs ont été relues le 16 octobre. Les liens X du flux n’ont pas pu être relus (403 via Web, lecture OpenCLI interrompue après absence de réponse) ; ils ne sont pas présentés comme une vérification directe.

Choix : changement d’interface, économie des petits modèles, ouverture des modèles européens, traçabilité des médias. Les doublons Mistral des 6 et 7 octobre sont fusionnés. Les autres annonces restent dans la veille : ce pilote est une sélection éditoriale, pas un compte rendu exhaustif.

Nuances conservées :
- GPT-6 avait déjà été introduit en septembre ; le 7 octobre élargit l’accès avec Intelligent UI. L’interface Halloween est un exemple fictif.
- Le coût Haiku annoncé par Anthropic est une moyenne et dépend des usages. Aucun benchmark ni tarif universel inventé.
- Mistral : préversion API le 6 octobre ; poids annoncés fin octobre. Les pages techniques divergent entre 49 et 52 milliards de paramètres actifs : chiffre écarté.
- SynthID détecte son filigrane ; l’absence de détection n’est pas une preuve d’origine humaine (inférence sur le périmètre documenté). La citrouille et la ficelle sont un gag fictif.

Tous les dialogues appartiennent aux personnages fictifs ; aucune citation d’un dirigeant. Les machines et interfaces illustrées sont des métaphores. Le texte HTML reste séparé des dessins pour la lisibilité et les corrections. Chaque planche source comporte six cases sans texte ; le lecteur montre chacune à la largeur du téléphone.
