# Entrée pour Claude

Ce dossier contient la bibliothèque de la BD Veille IA de Hugo.

Lire et appliquer `AGENTS.md`, puis `docs/BIBLE.md`, `docs/PRODUCTION.md` et `manifest.json`. Ne pas dupliquer ces consignes dans une seconde version divergente.

Ouvrir `index.html` pour examiner les planches. Sélectionner les fichiers par leur identifiant du manifeste. L’absence d’un outil de génération d’images ne doit pas être compensée par des personnages improvisés en code : réutiliser les visuels disponibles ou fournir le brief graphique manquant.

La fiche V2 est canonique. Les images `proposed` ne sont pas validées. Les scripts d’épisodes doivent être sourcés séparément des illustrations. La publication reste soumise à l’accord de Hugo.
