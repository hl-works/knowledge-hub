Chat, Cowork, or Code: which to use (and the famous "terminal")

Three ways to use Claude depending on the task — talk, delegate, act — and the truth about the "terminal," which looks scary but installs with one command. Along with what changed in 2026: Cowork everywhere, Code in the browser and on mobile, and routines that run without your machine.

By Hugo Lahutte · May 31, 2026 · Updated September 1, 2026 · ~7 min read

30-second take

  • Chat: you talk, it produces text, analyses, ideas — with its memory and your connected tools. The interface you already know.
  • Cowork: you delegate real office work to it (prepare a doc, dig through files, fill out a form in its built-in browser, run a routine) — designed for non-developers, on desktop, web, and mobile.
  • Code: it acts directly on your files, your project, your site — the most powerful option. In the "terminal" (one command to paste), but also in the browser, the app, or your phone, where the session runs in the cloud.

1. Chat, Cowork, Code: which for what

They're three doors into the same Claude, to pick based on what you want to do:

  • Chat (web, mobile, app) — the conversation. To think, write, analyze a document, prepare a strategy. 90% of people start and stay here, and that's perfectly fine. In my setup, that's where everything in my voice gets written — and we stop at the validated text: no HTML, no publishing.
  • Cowork — an assistant that carries out office work end to end, for someone who doesn't code. It handles files, a spreadsheet, a presentation; it opens a browser in its panel to fill out a form or finish an online process; it runs scheduled routines; it shares its memory with chat. The step between "talking" and "delegating."
  • Code — the agent that gets its hands dirty: it reads and edits your files, runs commands, manages a code repository, deploys a site, updates all the cross-links of a page. That's what I run Cobra with and how I publish this site. Not reserved for devs: it's just the "it acts, it doesn't just answer" level.

My boundary rule, which structures all my work: Chat writes, Code executes. A Chat session produces a validated text; Code turns it into a deliverable. The two halves don't share the same success criterion — the accuracy of the message on one side, conformity to the template on the other — and mixing them in a single session means losing both. Details in my method.

2. What "the terminal" is, and why it shouldn't hold you back

The terminal is just a window where you type commands instead of clicking buttons. It has a "hacker movie" vibe that intimidates, but it's an interface like any other.

And above all: you don't need to master it. The strategy is dead simple — you copy, you paste, you hit Enter. If a command gets stuck, you paste the error to Claude and it tells you what to do. You learn by doing, no course required.

3. Installing Claude Code, really easily

No need to install anything else anymore: a single command to paste in the terminal.

On Mac (or Linux) — open Terminal, paste, Enter:

curl -fsSL https://claude.ai/install.sh | bash

On Windows — open PowerShell, paste, Enter:

irm https://claude.ai/install.ps1 | iex

Then you check, and you launch:

claude --version
claude

On first launch, it opens your browser to sign in to your Claude account. You need a paid subscription — and good news: every paid plan includes Claude Code and Cowork, from the Pro plan (about twenty dollars a month) to the Max plans; what changes between them is usage volume.

And if the terminal really puts you off, you have three other doors: the desktop app (Mac/Windows), which runs Claude Code without a terminal, Claude Code in the browser (the session runs in the cloud, on a copy of your project, nothing to install), and the mobile app — I launch fixes from my phone, and check them live a minute later.

Official details: code.claude.com/docs/en/setup.

4. Do you need a big computer? (No.)

Let's demystify: all the computation happens on Anthropic's servers, not on your machine. You do not need a gamer graphics card or a monster — your computer only sends and receives text.

A year ago, I recommended a machine that stays on 24/7 to host your automations. That's less and less necessary: Claude Code on the web and Cowork run in the cloud, and scheduled routines run without your machine. My little always-on Mac is now only used for what genuinely has to run at my place. The real comfort of a good computer is running several sessions in parallel without lagging — not computing power.

5. What changed in 2026

For those who read the first version of this guide, in May:

  • Cowork left the desktop. Desktop, web, and mobile for every paid plan (August); a built-in browser to finish an online process; the ability to teach Claude a skill by recording your screen; memory shared with chat; scheduled routines; a plugin marketplace.
  • Code left the terminal. Browser, desktop app, mobile — the session runs in the cloud. Auto mode (Claude decides routine permissions on its own, with protections against manipulation) became the default in August. Subagents work in the background, workflows orchestrate several agents, Artifacts produce shareable pages from a session, and a cleanup command tidies up unused skills and context files.
  • Chat acts. Connectors no longer just read: Claude can send a reply in Gmail or file a document in Drive, with validation on the actions that matter.
  • The models. The Claude 5 family — Sonnet 5, Opus 5, Fable 5.1 — made Code capable of autonomous tasks lasting several hours. It's no longer "it writes a function," it's "it ships a feature, tested."
