Method v2.1: no more base file — memory, auto mode, loops and the browser

Claude · HL · September 2, 2026 · Perso
metaagentdocen-prodPerso

Context

Yesterday, Method v2 described two layers of context: versioned CLAUDE.md files (“how to work with me”) and the Brain (“what we know”). It was already wrong on the day it was published, and I'm the one who flagged it while rereading: since the summer, I no longer have a base instruction file. The way I steer AI changed on four points in a month — memory, auto mode, loops and routines, the browser — and the site had to say so.

What was done

  • No more base file. Since August 25, Claude's memory is a single one shared between the chat and Cowork, on by default, reviewable and correctable topic by topic; Claude Code keeps an automatic memory per project, where it writes down my corrections itself. The tone, the principles, “one question at a time,” my job: remembered, not copied over. What's still written by hand: the CLAUDE.md of a code repository — conventions, commands, forbidden actions — short, versioned, read by any human or agent working on it. This site has one; it's the house rules, no longer a personality file.
  • Auto mode. The default in Claude Code since August 14: you no longer validate each command, a classifier reviews every action, my written prohibitions take precedence over it. My practice: I validate the result — the diff, the health-check script, the page live online — and the writes into my business tools stay behind a preview and a button.
  • Loops and routines. A growing share of the work no longer happens in a conversation, it runs: a loop to monitor a deploy this afternoon, a weekly read-only consistency routine, home-made scheduled tasks for what has to run forever.
  • The browser. Since August 26, Claude browses: the Claude in Chrome extension in my own browser, or Cowork's built-in browser, separate from my tabs and passwords. It's the door for everything that has no connector — supplier portals, back offices, administrative procedures — with the same rule: Claude reads and fills in, the click that commits stays mine.
  • On the site: the Method rewritten as v2.1 (twelve sections, a new starting prompt with no file), and thirteen guides adjusted — the CLAUDE.md “when you still need one,” context, Chat/Cowork/Code with a browser section, loops, agents (five forms), skills, the Brain, the prompt, the principles, Compound Engineering, the guardrails with auto mode, data, the retailer. The glossary follows (memory, auto mode, browsing, CLAUDE.md redefined).

What was hard or unexpected

Admitting that a page written the day before was already dated. Method v2 had been rewritten “as of today” on September 1, from the Brain — and the Brain itself still described August's CLAUDE.md profiles. A stale brain is worse than an empty brain: the Claude Profiles page needs updating, and that's an act I'll do myself, not a sync.

Not throwing out the file with the personality. The temptation was to write “the CLAUDE.md is dead.” That's wrong: a repository's file has never been so useful, precisely because auto mode executes without asking. What disappears is the base file; what stays is the house rules.

Stack

Claude Fable 5.1 in Claude Code (cloud session), the site's AI Watch as the chronology (unified memory on August 25, the Cowork browser on the 26th, auto mode on the 14th), web checks on the dates and the scopes (Claude in Chrome generally available on all paid plans; the auto mode classifier and Anthropic's study on a thousand testers), the session's page generators, the site's consistency check.

What it illustrates

A method for working with AI goes stale in weeks, not months. The reflex that saves you isn't rewriting everything at every announcement, it's having a dated place where you say what changed — and leaving to memory what no longer needs to be written down.
