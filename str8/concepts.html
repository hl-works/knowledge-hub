Str8
Posture & training · app perso · mobile-first · PWA hors-ligne

Trois directions artistiques pour Str8, avant de développer l'app complète. Chaque concept montre l'écran d'accueil et l'écran de séance réels (compteurs et timer manipulables). Aucun compte, aucune base de données — tout vit dans le navigateur.

★ Recommandation par défaut

Si tu ne tranches pas : Concept A — Editorial Sport. C'est le plus original, le plus lisible à une main et le moins « généré par IA ». Une réserve utile : l'écran de séance est le cœur de l'app (timer + compteurs) — j'y grefferais la clarté « instrument » du Concept B pour les gros chiffres. A pour l'identité, la rigueur data de B pour le chrono.

Décisions techniques déjà tranchées Stockage vidéo dans le navigateur = jouable via IndexedDB (Blob + createObjectURL, install PWA iOS incluse) → tes vraies vidéos remplaceront les animations plus tard. On démarre sur des animations SVG/CSS (visibles dans les écrans de séance). Repo zéro-build → app finale en vanilla PWA statique, pas Next.js.

Et ensuite

Une fois le concept choisi, l'ordre de dev :

  1. Design system final du concept retenu
  2. Structures de données + bibliothèque des 25 exercices
  3. Écran de séance → timers → compteurs modifiables → gestion des séries
  4. Stockage local (localStorage + IndexedDB), export/import JSON & CSV
  5. Programme 12 semaines · routine 5 min · progrès
  6. PWA (manifest, service worker, offline) · animations SVG · doc « remplacer par mes vidéos »
